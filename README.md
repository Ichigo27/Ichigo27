Welcome to my GitHub! I'm a Data Scientist at RxLogix Corporation, building agentic AI and NLP systems for healthcare and pharmacovigilance. I focus on multilingual clinical NER, LLM-powered extraction pipelines, and Model Context Protocol (MCP) microservices running on AWS Bedrock.

<img align="right" alt="img" src="https://github.com/FernandoRoldan93/FernandoRoldan93/blob/master/cover_image.jpg" width="50%" height="auto" />

#### 🧠 What I do:
- Build a production multilingual clinical NER engine that extracts 11+ pharmacovigilance entity categories from English & Japanese case narratives, PDFs, and E2B XML
- Architect agentic MCP microservices for adverse-event triage and natural-language case-series summarization, coupling DuckDB analytics with AWS Bedrock Converse tool-use loops
- Secure multi-tenant AI pipelines with AES/KMS encryption, Oracle VPD row-level security, and Bedrock prompt caching to cut latency and token cost
- Design LLM-as-a-judge auto-evaluation frameworks to reduce manual QA effort

#### 🧰 My go-to tools:
- **Languages & Frameworks:** Python, SQL, FastAPI, Flask, LangChain, LangGraph
- **AI & GenAI:** AWS Bedrock (Claude, Converse API, Prompt Caching, Batch Inference), Model Context Protocol / FastMCP, RAG, spaCy, NLTK, LLM-as-a-judge
- **Data & Infra:** DuckDB, OpenSearch (k-NN vector search), Redis (pub/sub), Oracle (VPD), PostgreSQL, Pinecone, Docker, AWS (SQS, S3, Secrets Manager, KMS)

#### 🤝 I care about:
- Transparent and responsible AI
- Collaborative problem solving across tech + domain teams
- Mentoring and sharing practical NLP/LLM knowledge
