Welcome to my GitHub! I'm a Data Scientist who’s passionate about turning messy, unstructured data into something useful and actionable. I currently work on building NLP and LLM-powered tools—mostly for healthcare and pharmacovigilance use cases.

<img align="right" alt="img" src="https://github.com/FernandoRoldan93/FernandoRoldan93/blob/master/cover_image.jpg" width="50%" height="auto" />

#### 🧠 What I do:
- Develop multilingual NLP pipelines that extract 50+ medical entities from free-text reports (spaCy, BioBERT, fuzzy matching)
- Build LLM-based chatbots to collect missing data with AWS Bedrock & Claude Sonnet
- Create auto-evaluation frameworks to reduce manual QA efforts (with fuzzy/LLM-based comparisons)
- Design systems that are scalable, compliant, and auditable for real-world deployment

#### 🧰 My go-to tools:
- **Languages & Libraries:** Python, spaCy, BioBERT, scikit-learn
- **Infra & DevOps:** Docker, Redis, AWS Bedrock
- **Other:** Prompt engineering, multilingual support, NLP evaluation metrics

#### 🤝 I care about:
- Transparent and responsible AI
- Collaborative problem solving across tech + domain teams
- Mentoring and sharing practical NLP knowledge
